# Python Sorting Algorithm Comparison

## Overview
An independent programming project exploring three sorting algorithms in Python: optimised bubble sort, selection sort and insertion sort.

## Features
- Implements three sorting algorithms.
- Counts element comparisons and swaps or shifts.
- Uses Python's `timeit` module to measure execution time.
- Compares performance using ascending and descending input lists.
- Repeats timing measurements to observe execution-time variation.

## Concepts Demonstrated
- Python functions and lists
- Loops and conditional logic
- Sorting algorithms and algorithmic complexity
- Performance measurement and testing
- Comparing best-case and worst-case input patterns

## How to Run
1. Install Python 3.
2. Run `python3 compare_timeit.py` from the terminal.
3. Review the reported timing measurements for each algorithm.

## Learning Outcome
This project explores how different sorting algorithms behave with different input arrangements and how comparisons, data movement and execution time can be used to examine algorithm performance.

## Scope
An independent learning project developed to practise Python programming and algorithm analysis.
